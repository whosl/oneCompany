# OneCompany

OneCompany 是一个本地优先的多智能体应用开发系统。用户通过 TUI2 输入一句业务需求，系统依次完成需求澄清、PRD 与验收标准生成、技术方案确认、TDD 开发、测试、部署确认和交付导出。

正式提交入口为 TUI2。仓库不包含旧版 TUI 或 OneCompany Web 控制台；系统生成的目标应用仍以可在浏览器中访问的 Web App 为默认交付形态。

## 环境要求

- Node.js 22+
- pnpm 9+
- Git
- mimo CLI 或 OpenCode CLI
- 至少一个 OpenAI-compatible 模型 API Key
- Docker（可选，用于容器运行和高风险沙箱）

## 安装

```bash
pnpm install
cp .env.example .env
pnpm migrate
```

根据 `.env.example` 配置工作流模型和编码模型。正式验收不要设置 `OC_USE_STUB_ENGINE=1`。

## 启动

终端一启动 API：

```bash
pnpm api
```

终端二启动 TUI2：

```bash
pnpm tui2
```

也可以启动与 TUI2 同步的 WebUI：

```bash
pnpm webui
```

打开 `http://localhost:3010`。开发服务器默认把 `/api` 代理到
`http://127.0.0.1:3001`；连接其他 API 时可在 `apps/webui/.env.local`
中设置 `VITE_API_URL`。

也可以直接打开指定项目：

```bash
pnpm tui2 --project <project-id>
```

## Docker

容器默认运行 API：

```bash
docker compose up --build -d
docker compose exec onecompany pnpm tui2 --api http://127.0.0.1:3001
```

## 验证

```bash
pnpm build
pnpm typecheck
pnpm test
```

## 核心流程

1. TUI2 Project Hub 创建项目并输入一句需求。
2. 需求 Agent Group 分析需求、评分并循环追问缺口。
3. 用户回答问题或采用显式默认假设。
4. 系统生成 PRD 和验收标准，并等待需求确认。
5. 开发 Agent Group 生成技术方案、测试设计和功能切片计划。
6. Opencode Harness 按 TDD 循环读取、编辑代码并执行测试。
7. OneCompany 独立执行权威测试、审查、预览和风险检查。
8. 用户确认部署与最终验收，系统导出生成应用和结构化记录。

## 主要模块

```text
apps/api                 Hono API、SSE 和工作流入口
apps/tui                 TUI2 项目中心与项目控制台
packages/agent-core      Agent 注册、模型执行器、Opencode Harness
packages/workflow        LangGraph 需求与开发工作流
packages/workspace       工作区、Git、Shell、测试与沙箱
packages/integrations    MCP、Native Adapter 和离线 Skill Pack
packages/shared          SQLite、事件协议和共享 Schema
packages/oc-gateway-mcp  受治理的 MCP Gateway
```

考试提交说明见 `docs/week3-level2-submission.md`。

## Included Generated Application

The submission archive includes an AI interview assistant generated by OneCompany:

```bash
cd generated_app
npm install
npm run verify
npm run dev
```

Open `http://127.0.0.1:3000`. Structured requirement, plan, acceptance, delivery, and verification records are under `artifacts/`; the exported tool-call log is under `logs/`.
